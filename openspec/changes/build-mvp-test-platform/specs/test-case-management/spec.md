# Spec Delta

## Purpose

定义并管理接口测试用例：记录请求定义与断言规则，供执行引擎与测试案例集使用。

## ADDED Requirements

### Requirement: 创建测试用例

系统 SHALL 允许管理员创建测试用例，用例包含名称、请求方法、请求 URL、请求头、请求体、以及断言规则（如期望状态码、期望响应体匹配）。

#### Scenario: 创建成功

- **WHEN** 管理员提交包含名称、请求方法与 URL 的合法用例
- **THEN** 系统保存该用例并返回用例标识

#### Scenario: 缺少必填字段

- **WHEN** 管理员提交缺少名称、请求方法或 URL 的用例
- **THEN** 系统拒绝创建并返回校验错误

### Requirement: 查看测试用例

系统 SHALL 允许管理员按列表查看测试用例，并查看单个用例的完整详情。

#### Scenario: 查看列表

- **WHEN** 管理员请求测试用例列表
- **THEN** 系统返回用例列表，每个用例至少包含名称与更新时间

#### Scenario: 查看详情

- **WHEN** 管理员请求某个用例的详情
- **THEN** 系统返回该用例的完整请求定义与断言规则

#### Scenario: 查看不存在的用例

- **WHEN** 管理员请求一个不存在的用例
- **THEN** 系统返回未找到错误（HTTP 404）

### Requirement: 更新测试用例

系统 SHALL 允许管理员修改已存在用例的字段。

#### Scenario: 更新成功

- **WHEN** 管理员提交对某用例字段的合法修改
- **THEN** 系统保存修改并返回更新后的用例

### Requirement: 删除测试用例

系统 SHALL 允许管理员删除测试用例。

#### Scenario: 删除成功

- **WHEN** 管理员删除一个存在的用例
- **THEN** 系统删除该用例，后续查询返回未找到

#### Scenario: 删除不存在的用例

- **WHEN** 管理员删除一个不存在的用例
- **THEN** 系统返回未找到错误（HTTP 404）
