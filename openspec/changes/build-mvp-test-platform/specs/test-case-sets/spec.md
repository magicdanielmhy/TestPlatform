# Spec Delta

## Purpose

把测试用例分组组织为"测试案例集"，便于批量管理与执行一组相关的接口测试。

## ADDED Requirements

### Requirement: 创建测试案例集

系统 SHALL 允许管理员创建测试案例集，案例集至少包含名称。

#### Scenario: 创建成功

- **WHEN** 管理员提交包含名称的案例集
- **THEN** 系统保存该案例集并返回案例集标识

#### Scenario: 缺少名称

- **WHEN** 管理员提交缺少名称的案例集
- **THEN** 系统拒绝创建并返回校验错误

### Requirement: 管理案例集中的用例

系统 SHALL 允许管理员向案例集添加测试用例，或从案例集移除测试用例。

#### Scenario: 添加用例

- **WHEN** 管理员将一个已存在的用例加入某案例集
- **THEN** 该用例成为该案例集的成员

#### Scenario: 移除用例

- **WHEN** 管理员从某案例集移除一个成员用例
- **THEN** 该用例不再是该案例集的成员，但用例本身仍被保留

### Requirement: 查看测试案例集

系统 SHALL 允许管理员查看案例集列表，并查看单个案例集及其成员用例。

#### Scenario: 查看列表

- **WHEN** 管理员请求案例集列表
- **THEN** 系统返回案例集列表，每个案例集至少包含名称与成员数量

#### Scenario: 查看详情与成员

- **WHEN** 管理员请求某个案例集的详情
- **THEN** 系统返回该案例集信息及其成员用例列表

### Requirement: 删除测试案例集

系统 SHALL 允许管理员删除测试案例集；删除案例集不删除其成员用例。

#### Scenario: 删除成功

- **WHEN** 管理员删除一个存在的案例集
- **THEN** 系统删除该案例集，其成员用例仍被保留
