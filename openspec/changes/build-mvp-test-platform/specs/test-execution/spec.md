# Spec Delta

## Purpose

执行接口测试用例（发送 HTTP 请求并应用断言），记录并展示每次执行的结果。

## ADDED Requirements

### Requirement: 执行单个测试用例

系统 SHALL 允许管理员触发单个用例的执行：按用例的请求定义发送 HTTP 请求，应用其断言规则，并得出通过或失败的结果。

#### Scenario: 断言通过

- **WHEN** 管理员执行一个用例且实际响应满足其所有断言
- **THEN** 系统记录该次执行结果为"通过"，并保存响应状态码与响应体

#### Scenario: 断言失败

- **WHEN** 管理员执行一个用例且实际响应不满足任一断言
- **THEN** 系统记录该次执行结果为"失败"，并保存实际响应状态码与响应体

#### Scenario: 执行请求异常

- **WHEN** 执行用例时无法完成请求（如连接失败、超时）
- **THEN** 系统记录该次执行结果为"错误"，并保存失败原因

### Requirement: 执行整个测试案例集

系统 SHALL 允许管理员触发整个案例集的执行，逐个执行其成员用例并汇总结果。

#### Scenario: 批量执行

- **WHEN** 管理员触发某案例集的执行
- **THEN** 系统执行该案例集内所有成员用例，并返回每次执行的结果与汇总（通过/失败数量）

### Requirement: 查看执行结果

系统 SHALL 允许管理员查看历史执行记录，包括每次执行的结果、响应信息与失败原因。

#### Scenario: 查看单次结果

- **WHEN** 管理员请求某次执行的结果
- **THEN** 系统返回该次执行的结果、请求定义、响应状态码、响应体与断言结果

#### Scenario: 查看用例的最近结果

- **WHEN** 管理员请求某用例的执行历史
- **THEN** 系统返回该用例的历次执行结果，按时间倒序排列
