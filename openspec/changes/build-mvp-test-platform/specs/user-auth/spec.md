# Spec Delta

## Purpose

认证管理员身份、签发访问凭证，并保护测试平台的受保护资源不被未授权访问。

## ADDED Requirements

### Requirement: 管理员登录

系统 SHALL 提供登录接口，单一管理员账号使用用户名与密码登录；校验通过后签发访问令牌（JWT）供后续请求使用。

#### Scenario: 登录成功

- **WHEN** 管理员使用正确的用户名与密码调用登录接口
- **THEN** 系统返回访问令牌（JWT）与令牌有效期

#### Scenario: 登录失败

- **WHEN** 管理员使用错误的用户名或密码调用登录接口
- **THEN** 系统拒绝登录，返回认证失败错误，且不签发任何访问令牌

### Requirement: 受保护资源需要认证

系统 SHALL 拒绝任何未携带有效访问令牌的请求访问受保护资源。

#### Scenario: 无令牌访问

- **WHEN** 客户端未携带访问令牌访问受保护接口
- **THEN** 系统返回未认证错误（HTTP 401）

#### Scenario: 令牌无效或过期

- **WHEN** 客户端携带无效或已过期的访问令牌访问受保护接口
- **THEN** 系统返回未认证错误（HTTP 401），不返回业务数据
